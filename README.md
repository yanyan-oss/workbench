# 工作台

> 个人待办 · 日历 · 复盘 · 报告工作台（网页版 PWA）。手机、电脑通用，全程 **0 元**。

## 快速上手（发文件即用）

1. 拿到这个文件夹（或解压 zip）。
2. 双击 `index.html` —— 浏览器自动打开，立刻能用。**不用装任何东西、不用联网、不用注册账号。**
3. 想体验更好（能装成独立 App、能离线）：先装 Node.js（<https://nodejs.org>），再双击 `启动工作台.bat`。

> 想让别人用网址访问（不用发文件），见「进阶：放到 GitHub Pages」。

## 主要功能

| 功能 | 说明 |
|---|---|
| 速记 | 每行写一条任务，回车自动解析日期 / 时间 / 时长 / 完成度 |
| 日历 | 左侧月历，点某天看、改那天的任务 |
| 任务 | 完成度、时间、子任务、删除 |
| 复盘 | 写每天总结 + 改进建议（自动进入「改进追踪」） |
| 报告 | 日报 / 周报 / 月报，可复制文字或生成长图 |
| 备份 / 导入 | 导出 JSON 备份、从备份恢复 |

**速记写法示例**：`明天 开会` · `下周三 交报告` · `11月20日 15:00 交方案书` · `这个月留2小时 复习` · `做方案书 完成80%`

## 三个层级：功能是怎么配出来的

| 层级 | 功能 | 需要准备 |
|---|---|---|
| ① 本地使用 | 记任务 / 日历 / 复盘 / 报告 | **什么都不用**，双击即用 |
| ② 云同步 | 手机、电脑数据互通 | 一个 **GitHub 账号 + 一个令牌** |
| ③ 微信推送 | 每晚 23:00 把「明日待办」推微信 | **Server酱 + GitHub 仓库两个密钥** |

> ⚠️ **只有层级 ① 能「发个文件、双击就用」。** 层级 ②③ 涉及**个人密钥/账号**，没法靠发文件直接给——每个人要**用自己的账号**配一次（令牌是个人隐私，不能共享）。

## 层级 ① 本地使用

1. 把整个文件夹（或打包成 zip）发给别人。
2. 别人解压后：
   - 简单用 → 双击 `index.html`；
   - 完整体验 → 先装 Node.js，再双击 `启动工作台.bat`。
3. 完事，0 配置，数据存在使用者自己的浏览器本地。

## 层级 ② 云同步（跨设备互通）

> 每个人用**自己的账号**做，令牌不能共享。

### 1. 创建 GitHub 令牌（PAT）
1. GitHub → 右上头像 → **Settings** → 左下 **Developer settings**
2. **Personal access tokens → Fine-grained tokens → Generate new token**
3. 填：
   - Token name：`工作台`
   - Expiration：`No expiration`
   - **Account permissions → Gists → 选 `Read and write`**（其余保持默认）
4. 点 **Generate token**，复制（形如 `github_pat_…`，**只显示一次**，先存好）

### 2. 在工作台里连上同步
1. 打开工作台 → 右上「**同步**」
2. 粘贴刚复制的令牌 → 点「**连接**」
3. 提示「已连接云同步」即成功（首次会自动建一个**私密 Gist** 存数据）

### 3. 其他设备也连一次
- 手机、另一台电脑打开工作台 → 「同步」→ 粘贴**同一个令牌** → 「连接」。
- 两台设备就连通了：一端改了，另一端自动同步。

> 数据存在你自己的**私密 Gist** 里，只有你的令牌能读写，别人看不到。

## 层级 ③ 微信每晚推送（Server酱 + GitHub Actions）

### 1. 注册 Server酱，拿 SendKey
1. 打开 <https://sct.ftqq.com>，用微信扫码登录
2. 点「**SendKey**」，复制那个 key（形如 `SCT...`），存好

### 2. 把项目放到你的 GitHub 仓库
1. GitHub → 右上 **＋ → New repository** → 名字 `workbench` → **Public** → Create
2. 上传这些文件（仓库页 **Add file → Upload files** 拖进去，Commit）：
   - `index.html`、`manifest.json`、`sw.js`、`icon-192.png`、`icon-512.png`
   - `push-tomorrow.js`、`.github/workflows/daily-push.yml`
3. 开 Pages：仓库 **Settings → Pages → Source 选 `Deploy from a branch` → Branch 选 `main` → Save**，等 1–2 分钟得到网址 `https://你的GitHub用户名.github.io/workbench/`

### 3. 配两个密钥（secrets）
1. 仓库 **Settings → Secrets and variables → Actions → New repository secret**
2. 分别添加两个：
   - 名字 `GIST_PAT`，值 = 你的 **GitHub 令牌**（和层级②同一个）
   - 名字 `SENDKEY`，值 = 你的 **Server酱 SendKey**

### 4. 先触发一次同步（让数据 Gist 存在）
- 用浏览器打开你的 Pages 网址 → 「同步」→ 粘贴令牌 → 连接一次。这样数据 Gist 才会被创建。

### 5. 测试推送
- 仓库 **Actions → 左侧「每日推送明日待办」→ Run workflow → 绿色 Run workflow**，手动跑一次。
- 跑完微信应该收到一条「明天 … 待办」。以后每天 **23:00（北京时间）** 自动推。

## 进阶：放到 GitHub Pages（让别人用网址访问，不用发文件）

1. 照层级③第 2 步建公开仓库、传文件、开 Pages。
2. 得到网址后，直接发给别人：`https://你的GitHub用户名.github.io/workbench/`
3. 别人浏览器打开即用（核心功能全免费）。别人要云同步，就自己再走一遍层级②（用**自己的**令牌）。

> ⚠️ 坑：GitHub Pages 对**中文文件名**会 503/404，所以主文件必须叫 `index.html`（本项目已经是这样）。别把网页文件改回中文名。

## 进阶：装成独立 App（手机/电脑桌面图标，点开像 App）

> 前提：必须先有一个 **HTTPS 网址**（就是上一节部署出来的网址）。手机上没有「双击文件」这回事，必须先能打开网址，才能装成图标。

### 电脑端（Windows / Mac）
1. 用 **Chrome 或 Edge** 打开网址。
2. 地址栏最右侧有个「安装」图标（一个带 ＋ 的小显示器/盒子）→ 点它 → 「安装」。
3. 桌面 / 开始菜单就会出现独立的「工作台」，双击打开是**独立窗口**（没有浏览器地址栏）。

### 安卓手机（重点：只有安卓自带浏览器，能不能弄出独立图标？）
> ⚠️ **能，但必须用 Chrome（或 Edge、Firefox、三星浏览器）。** 微信、QQ、UC、小米/华为自带等**国产浏览器不支持装成独立 App**——它们的「添加到桌面」只是加了个书签快捷方式，点开还是浏览器、也没有独立图标。

1. 手机装 **Chrome**（应用商店搜 Chrome，**免费**；多数国产手机自带或能免费装）。
2. 用 Chrome 打开网址。
3. 点右上 **⋮** → 「**安装应用**」/「**添加到主屏幕**」（不同版本名字略有差异）。
4. 桌面出现「工作台」图标，点开是**全屏独立窗口**，跟普通 App 一模一样。

> 如果只有国产浏览器、又不想装 Chrome：那就只能「添加到桌面」当书签快捷方式（体验打折扣）。**想真正像 App，就必须用 Chrome。**

### 苹果 iPhone / iPad（iOS）
1. 用 **Safari** 打开网址。
2. 底部中间「分享」按钮（方框里一个向上箭头）→ 往上滑 → 「**添加到主屏幕**」。
3. 桌面出现图标，点开接近全屏独立 App。

### 说明：本项目已经满足「可安装」条件
- `manifest.json`（应用名 / 图标 / 独立窗口）+ `sw.js`（离线缓存）都已配好，所以装出来就是**独立窗口 + 桌面图标 + 离线也能开**，不需要额外开发。
- 唯一硬性要求：必须走 **HTTPS 网址**（GitHub Pages 已是 https），或本机 `http://localhost`（`.bat` 起的服务）。
- **不能安装**的情况：直接双击 `index.html`（`file://`），或非 localhost 的 `http://`。
