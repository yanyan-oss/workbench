# 工作台

记录每日便签 + 日历 + 明日待办的本地网页工具（PWA）。

## 启动

双击 `启动工作台.bat`，会自动开一个服务窗口并打开浏览器 `http://localhost:8000`。

手动启动：在命令行里 `node server.js`。

## 安装成桌面/手机工具

浏览器打开后，地址栏右侧点「安装」图标（Chrome / Edge），即可作为独立窗口运行；手机浏览器里选「添加到主屏幕」。

## 数据与备份

数据存在浏览器本地（`localhost` 这个源），刷新不丢。右上角「备份」导出 JSON 文件，「导入」从备份恢复。建议定期点一下「备份」，把 JSON 文件存到别处。

## 文件说明

- `工作台.html` —— 主程序
- `server.js` —— 本地服务器（Node，无依赖）
- `manifest.json` / `sw.js` / `icon-*.png` —— PWA 安装与离线相关
- `启动工作台.bat` —— 一键启动

## 速记写法

每行一条任务，支持：`今天/明天/后天` `下周三` `这个月/下周` `这两天` `9点/下午3点` `2小时/两天` `完成80%` 等，回车添加。
